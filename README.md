# NUMBATs Hackathon

Welcome to the NUMBATs hackathon! This repository holds information and project ideas for the event.

## Hackathon projects

All project ideas can be found in this repository's issues: <https://github.com/numbats/numbathackathon/issues>.

Find a project that interests you, and group up with others to work on it!

At the end of the hackathon, groups will briefly showcase their projects.

## Code of Conduct

The complete Code of Conduct can be found here: [Code of Conduct](CoC.md).

Your participation means that you have agreed to this code of conduct.

In summary, we insist that all participants:

- Be respectful: Act professionally; no insults, harassment, or discriminatory behavior.  
- Be thoughtful: Include others, explain your thinking, help with coding and daily needs, and invite people to join in.  
- Be responsible: Look after your own safety and don’t endanger others.  
- Have fun: Try your best and use the event to learn new things.
